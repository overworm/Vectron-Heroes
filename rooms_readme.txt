## Классификация комнат (Lost Hero)

### Открытая комната
- Постоянно двигается лифт, ИЛИ
- Активирована платформа-невидимка как пол, ИЛИ
- Есть несущая платформа как пол, ИЛИ
- Набор тайловых безопасных пропастей / исчезающих платформ
- В открытых комнатах может находиться от 2 героев

Контур: полы, стены, платформы-невидимки.

### Закрытые комнаты

**Специальные для Domina** — только Domina через Stealth + юла.

**Специальные для Pengi** — тайловые стены с проёмом для слайда Pengi.

**Специальные для Refreezer** — проёмы в режиме обратной гравитации (только Refreezer активирует). Domina может залететь, но ничего не включит.

**Необратимые** — широкая пропасть или скрытая платформа-невидимка, без безопасных исчезающих платформ.

**Открываемые по триггеру** — неактивный лифт (вертикальный путь) и/или платформа-невидимка (горизонтальный путь).

**Открываемые по спуску** — исчезающие или промежуточные тайловые платформы; герои безопасно спускаются и открывают комнату автоматически.

**Открываемые с разрушением** — только Nerd (пролом платформы): ур.2 бак, ур.3 пролом в комнату босса.

### Правило смерти
Любое падение с высоты в **закрытую** комнату смертельно для любого персонажа.
Если персонаж оказался в закрытой без спецрежима / powered-лифта — смерть как от падения с большой высоты.
Комната открывается, когда в ней заработал лифт (или активирована невидимка / исчезающие панели по геймплею).
